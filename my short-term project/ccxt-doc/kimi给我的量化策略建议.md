你的策略思路很清晰：**全市场扫描 → 因子筛选 → 定期调仓**。针对这个框架，你需要的数据可以分为**核心必备层**、**因子构建层**和**风控辅助层**。

---

## 一、核心必备数据（地基）

### 1. 历史 K 线数据（OHLCV）
这是你最基础、最必须的数据，所有技术指标和大部分因子都从这里衍生：

| 字段 | 含义 |
|------|------|
| **Open** | 开盘价 |
| **High** | 最高价 |
| **Low** | 最低价 |
| **Close** | 收盘价 |
| **Volume** | 成交量 |

**时间周期建议**：
- 你计划每天/每半天调仓，至少需要**日线（1D）**和**4小时线（4H）**数据
- 如果因子涉及动量或短期反转，建议再准备**1小时线（1H）**作为辅助
- 回测时数据长度建议至少覆盖 **1-2 个完整牛熊周期**（加密市场建议 3-5 年）

### 2. 全市场币种清单（Universe）
你需要一张动态更新的"股票池"：
- 交易所支持交易的**所有币对**（如 BTC/USDT, ETH/USDT）
- **基础元数据**：上市时间、所属板块（Layer1、DeFi、Meme 等）、市值排名、是否可做空
- **过滤条件**：日均成交量低于某阈值的小币种要剔除（防止无法成交或滑点过大）

## 二、因子构建层（你的策略核心）

你说要用线性回归/机器学习筛选因子。因子通常分为几大类，你需要的数据源也不同：

### A. 技术面因子（从 OHLCV 计算即可）
这些不需要额外数据，用 K 线就能算：

| 因子类型 | 举例 |
|---------|------|
| **趋势类** | 均线偏离度（价格/MA20）、MACD、动量（过去 N 日涨跌幅） |
| **波动类** | ATR（平均真实波幅）、布林带宽度、波动率标准化收益 |
| **量价类** | 量价背离、OBV（能量潮）、资金流量比率 |
| **反转/均值回归** | RSI、KDJ、威廉指标 |

### B. 市场结构因子（需要额外数据）
| 数据 | 用途 |
|------|------|
| **订单簿数据**（买卖盘深度） | 计算买卖价差、订单簿失衡度（Bid/Ask 比例）、市场深度 |
| **资金费率**（合约市场） | 判断市场情绪极端程度，高费率往往预示顶部 |
| **持仓量（Open Interest）** | 衍生品市场热度，配合价格看是增量资金还是存量博弈 |
| **现货/合约价差** | 基差，反映市场乐观/悲观程度 |

### C. 链上因子（加密货币特有，非常有价值）
这是传统股票量化没有的"信息差"来源：

| 数据 | 含义 |
|------|------|
| **交易所净流入/流出** | 大额流入交易所通常预示抛压，流出则可能是屯币 |
| **活跃地址数** | 网络真实使用活跃度 |
| **大额转账预警** | 巨鲸动向 |
| **长期持有者持仓变化** | 判断筹码是在分散还是集中 |
| **矿工持仓/抛售** | 对比特币等 PoW 币种尤其重要 |

### D. 市场情绪/另类因子
| 数据 | 来源 |
|------|------|
| **社交媒体情绪** | Twitter、Reddit 提及量与情绪得分 |
| **Google 搜索指数** | 散户关注度（往往与顶部同步） |
| **恐惧贪婪指数** | 市场整体情绪极端值 |
| **新用户/新增钱包数** | 生态扩张速度 |

## 三、风控与执行层数据

光有因子不够，实际交易还需要：

| 数据 | 作用 |
|------|------|
| **手续费率** | 不同交易所 Maker/Taker 费率影响收益 |
| **最小下单量/价格精度** | 防止程序下单失败 |
| **历史资金费率** | 如果涉及合约对冲或杠杆 |
| **币种停牌/下架记录** | 回测时剔除已下架币种（防止幸存者偏差） |

## 四、给你的具体建议

### 阶段 1：MVP（最小可行产品）
先不要贪多，用最少的数据跑通闭环：

1. **Binance 或 OKX 的日线 OHLCV**（所有 USDT 币对，过滤掉日均成交额 < 100 万美元的）
2. **从 OHLCV 计算 20-30 个经典技术指标**作为初始因子池
3. **简单的动量 + 波动率 + 成交量因子**做基准策略

### 阶段 2：加入加密特色
当基础框架跑通后，逐步加入：
- 链上数据（通过 Glassnode、CryptoQuant 或自建节点）
- 资金费率数据（Binance API 可免费获取）
- 订单簿快照（适合更高频或做做市策略）

### 阶段 3：机器学习优化
- 用 **XGBoost / LightGBM** 做因子重要性筛选和组合权重
- 注意：**加密市场非平稳性强**，传统时序模型容易过拟合，建议用滚动训练（Walk-forward）而非简单划分训练/测试集
